
# Предсказание dropout студентов с курса

В этом ноутбуке представлено решение, состоящее из ансамбля **CatBoost**.

### Модели

- **`behaviour_v2`** — модель, которой подаются только базовые признаки, без истории, дневных значений.
- **`full_specialists`** — полный набор признаков, 75% предсказания - общая модель, 25% - отдельные модели конкретных курсов.
- **`full_Jweight`** — полный набор, но с повышенным весом(1.5) осенним студентам.
- **`cohort_local`** — базовые признаки, 75% предсказания - общая модель, 25% - отдельные модели конкретных курсов.

### Итоговые предсказания

В `submission.csv` и `submission_alternative.csv` они в итоге смешиваются в разных пропорциях:

- **`submission.csv`** — для `behaviour_v2`, `full_specialists` и `full_Jweight` сначала усредняются вероятности двух seed. Затем прогнозы каждой из трёх моделей переводятся в нормированные ранги и усредняются с равными весами.

- **`submission_alternative.csv`** — 75% ансамбля `behaviour_v2`, `full_specialists` и `full_Jweight` с одним seed `20261024` и 25% рангового прогноза `cohort_local`, усреднённого по двум seed. В первой части также используется усреднение рангов с равными весами.

### Эксперименты

Кроме итогового подхода, были попытки применить **LightGBM, XGBoost, CNN, GRU, TCN, transformers**, однако все они в итоге давали худшую метрику.
